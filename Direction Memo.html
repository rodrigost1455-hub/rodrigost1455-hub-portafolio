// the call

Verdict in one paragraph.

★★★★☆ → ★★★★★ blockers

V1 is aesthetically finished but narratively thin. The hero asserts seniority but doesn't prove it on first scroll. Projects are described, not argued. Motion is decorative, not diegetic. Fix those three and you stop competing with junior portfolios and start competing with founder profiles.

// keep — already on brand

  • Type pairing. Instrument Serif + JetBrains Mono is the right move for 2026 — Anthropic-coded, not template-coded.
  • Phosphor palette. Resist any urge to add a second accent hue. One color, used sparingly, reads senior.
  • CRT/scanline overlay. Subtle, identity-defining. Keep.
  • Stat-grid + skill-dot matrix. Strong scannable structure for recruiters.
  • Status-bar chrome. Real, not cosplay. Keep clock + git path.

// cut or rework

  • Hero h1 only. No proof, no live signal, no CTA. Below-the-fold ATS bait.
  • Project cards. They list projects. Recruiters can't see how you think.
  • ASCII art block. Decorative, not informative. Replace with a real architecture diagram.
  • Generic CTA. "Hiring for an AI Engineer?" is template-tier — make it sharper.
  • Decorative animations only. Fade-in is 2018. Need diegetic motion that signals competence.
// section 01

The hero is the entire pitch.

Recruiters give you 5 seconds. The hero must, in that window, communicate: (a) you ship production AI, (b) you are different from every other LLM-wrapper portfolio, (c) you are available now.

→ typography

  • Push h1 to clamp(72px, 11vw, 144px). Bigger than feels right. Confidence is a layout choice.
  • Two-line h1 with the second line italic + phosphor: I ship / production AI.
  • Add a serif sub-lede underneath (not mono) — breaks the wall of monospace and signals editorial control.

→ live system panel (right column)

  • Replace the static ASCII box with a live "ops" widget — animated request-rate sparkline (claude_api.latency), uptime counter that actually ticks, region tag (mx-north).
  • Show 2 production endpoints with green 200 OK pings every ~3s. It's theatre — but it's true theatre: you do operate live services.
  • The widget should look identical to a Grafana panel a hiring manager already reads at work.

→ proof bar (above the fold)

  • Slim row directly under h1: 9+ apps in prod · 1.8K SKUs migrated · 100% precision on Watson ML.
  • Each metric clickable → jumps to its case study. Recruiters scan, click, convert.

→ two real CTAs above the fold

  • Primary: $ hire rodrigo — phosphor pill, opens contact.
  • Secondary: $ cat cv.pdf — outline pill, downloads CV.
  • Tertiary hint: press / to search — invites the command palette (see Motion).
// section 02

Cards must become case studies.

Right now a project is one paragraph + tags. That's a résumé bullet. To convert at YC-adjacent shops, each project needs the four-beat structure every senior engineer recognises on sight:

  • Context — what was broken, in one sentence.
  • Decision — the engineering trade-off you owned (not "I used FastAPI").
  • Architecture — a real diagram, not ASCII art.
  • Impact — a number with a unit. Time saved, SKUs moved, latency cut.

→ the architecture diagram

  • Inline SVG, terminal-styled: hairline boxes, dashed connectors, phosphor labels on the wire.
  • Each box reads as a service:port — fastapi:8000, postgres:5432, claude.anthropic.com.
  • Animate the data flow with a traveling dot along each path — 4s loop. Hypnotic, technical, memorable.
  • On hover a node, surface a tooltip with the trade-off: e.g. asyncpg → statement_cache_size=0 // pgbouncer compat fix. That single hover state proves you've debugged production.

→ the metric block

  • One hero metric per project, set in serif italic at 72px. 98% faster. 1.8K SKUs. 100% precision.
  • Sparkline underneath, animated draw-in on viewport entry.

→ the "war story" pull-quote

  • One short paragraph per project styled as a terminal diff or // log block: the moment it broke, the moment it shipped. This is the storytelling beat that converts engineers — they recognise themselves.
  • Example for Axionix: // 3 a.m. — asyncpg crashes on every prepared statement behind pgbouncer. fix: statement_cache_size=0. ship.

→ visual differentiation per project

  • Axionix POS → multi-tenant network diagram (tenants → router → core services).
  • Yazaki QIR → workflow swimlane (operator → engineer → admin → SLA timer).
  • Watson ML → data pipeline (TXT → parser → 34 features → DT → Watson endpoint → Next.js).
  • Three different diagram shapes = three different visual signatures. Stops the "this is all the same project" effect.
// section 03

Diegetic motion, not decoration.

Linear, Vercel, Stripe, and Anthropic all share one motion principle: animation must mean something. Fade-ins are over. Here's the motion set V2 ships with:

→ ambient cursor light

  • Soft radial phosphor gradient follows the cursor at 0.4 opacity, screen blend mode, 480px diameter.
  • Makes the entire page feel lit by your attention. Costs ~3 lines of JS.

→ command palette (Cmd/Ctrl-K, or "/")

  • Linear-style modal. jump to projects, copy email, open axionix.app, download cv, toggle CRT.
  • Arrow-key nav, ↵ to execute. Sells your seniority before they read a single project.

→ boot sequence (first visit only)

  • ~1.4s overlay: terminal types $ boot rodrigo.santana@ai-engineer → [ok] services healthy → fades. Skips on return (localStorage).
  • Never make this longer. Never replay. Recruiters bounce on long intros.

→ data-flow dots on every architecture diagram

  • offset-path on SVG paths, animation: flow 4s linear infinite. Subtle, technical, on-theme.

→ hover states with meaning

  • Project cards: hairline border brightens, the file path in the header changes from main.py to README.md — telegraphs "click for the full story".
  • Skill rows: hover a tech tag, the entire column of related tags lights up. Shows the cluster.
  • CTAs: cursor enters → small ▍ caret appears next to the label, as if you'd just clicked into a terminal.

→ scroll-driven reveal (selective)

  • Only architecture diagrams and hero metrics get reveal animations. Everything else is static. Restraint reads as senior.
// section 04

Premium AI aesthetic, not SaaS slop.

The line between "AI infra company" and "SaaS template" is thin. Things that cross it:

  • Zero border-radius. Sharp corners on every card, button, badge. Rounded = consumer SaaS. Sharp = infra.
  • One accent colour, used surgically. Phosphor on numbers, dots, paths, hover states. Never on body text.
  • Hairline borders (1px solid #1f2826). Brighter on hover. Never thick, never colored.
  • Dotted-leader rules between metadata rows. Like Bloomberg, like a Stripe invoice, like an Anthropic doc.
  • No glassmorphism. No gradient meshes. No 3D blobs. If V2 has any gradient, it's the cursor glow and the section-end fade — nowhere else.
  • Editorial italics. Use Instrument Serif italic for the one phrase per section that carries the argument. Anthropic does this constantly; it's why their docs read smart.
// section 05

Conversion engineering.

Three high-leverage changes that make hiring a one-click decision:

  • Hireability strip at top of page — slim, phosphor-bordered: ● open to work · remote global · ai engineer · 30-day notice · response < 24h. Recruiters need this in the first 5 seconds.
  • "Why hire me" pull-quote before projects. Three sentences max. Production-shipped LLM systems + automotive-grade quality discipline = engineers who can be trusted with regulated workloads. Make the differentiator explicit.
  • End-of-page CTA, not contact form. Two buttons: $ email rodrigo + $ schedule 20min call (Calendly). Forms lose. Calendly converts.
// section 06

Mobile = first impression.

Half your traffic is recruiters tapping a LinkedIn link on their phone in a meeting. The current mobile collapse works but doesn't feel premium.

  • Replace the sidebar with a sticky bottom dock on mobile — three buttons, terminal-styled: menu, contact, cv.
  • Collapse the live ops widget into a single ticker line under the hero on mobile — keeps the signal, drops the bulk.
  • Architecture diagrams: overflow-x: auto with a phosphor scroll hint on the right edge. Don't squish them.
  • Increase mobile font baseline to 15px. The current 14px is too tight for fast scanning on a phone.
