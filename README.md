## 📦 Project Content

| Path | Description |
|---|---|
| **`index.html`** | The portfolio (v3). Single page, CRT / terminal-phosphor look: hero + status board, metrics, about, *how I work*, case studies, stack, experience, contact. |
| **`projects/`** | Detail page per new case study: `qualityhub.html`, `yia.html`, `eol-validation.html`. |
| **`assets/site.css`** | The original stylesheet, extracted unchanged from `index.html`. |
| **`assets/extra.css`** | v3 additions (status pills, about / method blocks, detail pages, contrast and mobile fixes). |
| **`assets/demo-*.svg`** | Demo charts (synthetic data). Generated by `tools/gen_demo_charts.py`. |
| `Portfolio v1.html`, `Portfolio v2.html`, `Direction Memo.html`, `uploads/` | Earlier versions kept for history. They are no longer linked from the site (see Confidentiality). |

No build step, no runtime dependencies: open `index.html`, or serve the folder (`python3 -m http.server 8000`).

## 🔒 Confidentiality rules

- No real part numbers, customers, people, internal line names, logs or screenshots.
- The employer appears only as "automotive Tier 1".
- Charts are **demo data** and labeled as such. To regenerate: `python3 tools/gen_demo_charts.py`.
- No impact metric (savings, hours, percentages) is claimed unless it was supplied. Missing ones are marked `TODO(rodrigo)` in the HTML.

## 🛠️ Editing

- **Add a project:** copy an `<article class="project">` in `#projects` (see the QualityHub card) and, if needed, a page from `projects/`.
- **Colors / type:** tokens in `:root` of `assets/site.css`.
- **Find open items:** `grep -rn "TODO(rodrigo)" .`

*Build: static HTML · zero runtime dependencies.*
